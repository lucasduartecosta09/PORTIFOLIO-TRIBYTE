# TRIBYTE

A TRIBYTE reúne Gustavo, Márcio e Lucas, estudantes de Desenvolvimento de Sistemas no SENAI. Neste portfólio, apresentamos nossos projetos acadêmicos, estudos de interface e trabalhos em desenvolvimento.

[Acessar o portfólio](https://portifolio-tribyte.vercel.app/)

## Projetos

| Projeto | O que você vai encontrar |
| --- | --- |
| [SENAI Smart Class](https://senai-smart-class-one.vercel.app/) | Painel de sensores e controles de sala, desenvolvido em equipe como projeto acadêmico. Sem o Arduino conectado, a demonstração usa leituras simuladas. |
| Painel comercial | Conceito de interface para acompanhar vendas e metas, com dados fictícios. |
| Vio Finanças | Projeto pessoal de Márcio Andrey para organização financeira, em desenvolvimento e ainda sem demonstração pública. |
| Portfólio TRIBYTE | Este site, feito em HTML, CSS e JavaScript para apresentar a equipe e seus trabalhos. |
